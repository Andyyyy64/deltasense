**精度を再実行して測る仕組みと、暫定ラベル付きの小規模評価を実装しました。**
このデータでは、使用した検出モデルの個数変化信号には見逃し・誤警報がありました。
セグメンテーションモデルは個数差が全件一致しましたが、誤検出が相殺されているため、

## 測定結果

主評価IoU=0.5の結果です。百分率だけでなく分子・分母を記載しています。

| 指標 | 検出モデル | セグメンテーションモデル |
|---|---:|---:|
| 個数差の符号・値が正しい比較 | 7/14（50.0%） | 14/14（100%） |
| 変化なしで個数変化信号が出た割合 | 4/11（36.4%） | 0/11（0%） |
| 個数変化信号の見逃し | 2/3（66.7%） | 0/3（0%） |
| 実際に個数が変わる組で符号・値が正しい比較 | 0/3 | 3/3 |
| 対象物体の認識Precision | 3/15（20.0%） | 3/17（17.6%） |
| 対象物体の認識Recall | 3/8（37.5%） | 3/8（37.5%） |
| 正解ラベルに支持される対応のPrecision | 3/13（23.1%） | 3/9（33.3%） |
| 期待する対応のうち正しく対応した割合 | 3/7（42.9%） | 3/7（42.9%） |
| 移動する人物の正しい対応 | 0/3 | 0/3 |

「個数変化信号」は、評価対象クラスの予測個数差が一つでも非ゼロという
**評価用の仮ルール**です。DeltaSense本体は物理的変化の判定を返しません。
信号の見逃しは、変化の方向や量の正しさとは別です。検出モデルの30→120秒は
信号自体は出ましたが、増減が逆でした。そのため、信号見逃しは2/3でも、
変化3組の符号・値の一致は0/3です。

認識のPrecision/Recallは、各画像の最初の観測を一度だけ集計しています。
同じ画像を使った複数のペアで認識成功数を水増ししていません。
対象外クラスの出力は別に保存し、部分的なラベルから誤検出と自動断定しません。

対応のPrecisionは、採用された対象クラスの対応のうち、両端が正解矩形へ
一対一に割り当てられ、同じ物体IDになったものの割合です。
支持されない対応には、誤検出同士の対応、位置不正確、誤ったID対応が含まれます。
すべてを「真の物体同士のID取り違え」と解釈することはできません。
未対応・曖昧な対応も、期待する対応があればRecallの失敗として数えます。

両端を正しく認識できた対応候補だけに絞ると3/3で対応しましたが、
これは静止画反復の人物・カップ・猫の3件だけです。人物が移動する場面での
成功を意味しません。IoUを0.3まで緩めても対応Recallは検出4/7、
セグメンテーション3/7で、移動する人物の対応成功は両モデルとも0/3でした。

## 失敗の具体例と解釈

- **人物なしの背景を人物として検出**：Apolloの80秒以降には対象人物が見えませんが、
  月着陸船の構造と影付近を人物として検出します。100→110秒、110→120秒、120→121秒では、
  検出モデルの偽の人物数が変わり、個数変化信号を出しました。
- **実在する人物を別クラスとして認識**：セグメンテーションモデルは、40秒の人物を
  bird、60秒の人物をdogとして検出しています。一方で背景をpersonとして検出するため、
  personの個数だけを見ても、実際の人物を追えているとは言えません。
- **個数差の偶然の一致**：60→80秒では、正解の人物数は1→0です。
  セグメンテーションモデルのperson予測は2→1で、差の−1だけは合います。
  前後の個数も、物体の位置も正解ではありません。
- **見逃しが前後で相殺**：コーヒー画像のスプーンをセグメンテーションモデルは
  両側で見逃します。予測0→0と正解1→1は差が同じゼロですが、認識は失敗です。
- **部分だけの検出**：検出モデルのスプーン矩形は柄を含む可視範囲の一部に留まり、
  正解矩形とのIoUが0.5未満になります。評価IoU=0.3では認識として数えられました。

この結果は、計算ロジックの不具合を示すものではありません。
DeltaSenseはモデルの出力を保存し、対応の根拠と未確認条件を残しています。
物理的な変化へ解釈する前に、認識モデルの適合性を評価する必要があります。

分母ゼロ、対象外クラスなど20件の独立した既知正解テストで検証しました。
