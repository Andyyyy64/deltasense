## ローカル検証時点の判定

**v0.1で定めた比較APIのローカル実装・検証・パッケージ準備を完了しました。**
公開リリースの完了とは分けます。リモートCIと配布の手続きは、以前の指示どおり保留です。
未公開・未コミットの候補は、ソース全体と配布物のSHA-256で識別します。

以前の「ローカル実装は完成」という判断には、検証の穴がありました。
今回、実際に旧実装で失敗するテストを作り、次の不具合を修正しました。

| 不具合 | 以前の検証が見逃した理由 | 修正・追加した検証 |
|---|---|---|
| 16bitのRGB・グレー＋alpha・RGBA PNGが8bitへ黙って変換される | Pillowのデコード後のモードだけで判定し、16bitグレーしか試していなかった | 元のPNGヘッダーで深度を確認。4種類の16bit PNGを、正常にデコードできる独立生成ファイルで検証 |
| マスクの書き込みを再有効化でき、面積・JSON・表示が食い違う | read-onlyフラグだけを確認していた。所有配列ではフラグを戻せる | 不変のbytesをバッファに使用。書き込みの再有効化を拒否 |
| マスクのshape変更やbefore/afterの代入で結果を壊せる | 入力配列の変更と辞書のコピーだけを確認していた | 観測は読み取り専用プロパティから独立したコピーを返す。元の観測や取得した配列の変更後もJSONと描画が一致 |
| 非常に大きい整数のしきい値でOverflowErrorが漏れる | 通常の範囲外・NaN・Infinityしか試していなかった | 数値の範囲を変換前に検査。conf・iou・match_iouの正負双方を検証 |
| ファイル属性の権限エラーがInputErrorにならない | ファイル読み込みの失敗だけを確認していた | 画像とcheckpointの属性確認も入力エラーに分類 |
| 有限の矩形でも面積比がInfinityになりJSON保存に失敗する | ゼロ除算だけを確認していた | 表現範囲を超える比率はnull＋`relative_delta_out_of_range`。元の面積と差分は保持 |

通常の対応規則、推論の既定値、微小差の保持、物理的変化を未確認とする仕様は維持しました。
領域外の比率にしきい値や丸めを入れて数値差を隠してはいません。

## 残る境界

ストックモデルの見逃し・誤検出、混雑や大きな移動での対応不足は残ります。
v0.1はモデルの予測を比較するAPIで、モデルの誤りを正解へ修正したり、現実の変化を
確定する機能ではありません。今回の補強によって人物認識の精度が上がったとは主張しません。
用途別の未使用データでの精度評価、GPU・他OS、v0.2の位置合わせは別の検証範囲です。

今後の正式配布時には、ライセンスと公開先を決め、現在の候補をcommitで固定し、
その候補のリモートCI合格と公開物の読取り・新規導入を確認する必要があります。
これらは意図的な保留であり、実施済みとして扱いません。
