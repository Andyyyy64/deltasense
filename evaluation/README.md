# 精度評価データの扱い

`pilot-v1.json` は、既存の静止画3枚とApollo映像の10フレームを使った
13画像・14比較ペアの小規模な評価用ラベルです。画像自体は配布物に含めません。
取得元・権利・クレジットは `docs/validation.md` を参照してください。

**ラベルはAIアシスタントによる目視の暫定版です。人による独立確認は未実施です。**
この実行の推論前に固定しましたが、一部の画像の過去のモデル出力は既知なので、
完全なブラインド評価でも、未使用の評価セットでもありません。

## ラベルの定義

- 画像の `sha256` と `size` が対象ファイルを固定します。
- `scope_class_ids` が評価対象です。人物0、猫15、カップ41、スプーン44を使用します。
  対象クラスの見える物体はすべて記載します。対象外の予測は別に保存します。
- `objects` の空配列は「対象クラスの物体が見えない」という明示的なラベルです。
  ラベルがない画像を空配列と推定する処理はありません。
- `bbox_xyxy` は元画像上の見える範囲の概略矩形です。遮蔽部分まで補完した矩形ではありません。
  離れた可視部分が同じ物体に属する場合、それらを囲む矩形です。
- `object_id` は同じ `scene` 内で一貫させます。両画像に同じIDがあれば期待する対応です。
  ApolloのIDは、この短い連続映像を目視して同一人物と推定したものです。
- `pairs` は推論前に選定しました。30/40/50/60秒は人物あり、80/90/100/110/120/121秒は
  対象人物なしです。10/20秒の部分的に見える人物と0秒のタイトルは、推論前に除外しました。
- 80→60秒は時間を逆にした評価です。実際の新しい入場撮影ではありません。
- マスク、正確な移動量、面積、物理単位の正解はありません。それらの精度は評価しません。

個数変化3ペアには、同じ退出の時間反転や別間隔での再利用が含まれます。
隣接フレームも相関があり、14件を独立した14場面として扱えません。

## 再実行

依存関係と元データ・モデルは `docs/validation.md` の手順で準備します。
フレーム抽出の使用環境はFFmpeg 7.0.2-staticです。異なるエンコーダーでPNGのバイト列が
変わった場合、digest不一致で停止します。既存ラベルを自動更新しません。

```sh
.venv/bin/python scripts/prepare_accuracy.py \
  --manifest evaluation/pilot-v1.json --assets artifacts

YOLO_CONFIG_DIR="$PWD/artifacts/yolo-config" \
  unshare --user --map-root-user --net .venv/bin/python scripts/evaluate_accuracy.py \
  --manifest evaluation/pilot-v1.json --assets artifacts --models artifacts/models \
  --output artifacts/accuracy-pilot/new-run --require-isolated-network
```

出力先は未作成のディレクトリを指定します。ラベルのコピー、画像への正解矩形の描画、
モデル出力JSON、比較画像、集計、設定、バージョン、チェックポイントとコードのハッシュを
保存します。元画像とラベルの不変性を検査し、ネットワーク操作も監査します。

## 人による確認と用途に合わせた追加

レビューする場合は、推論の描画を見ずに元画像と `truth-*.png` を確認してください。
既存の実行証跡を保つため、修正ラベルは `pilot-v2.json` など別ファイルに保存します。
確認者・日時・変更理由を記録し、独立した人が確認した場合だけ
`independent_human_review` を `true` にします。

対象用途の画像を追加する場合も、画像ID、元ファイルのdigest、寸法、評価対象クラス、
物体矩形と同一物体ID、ペア、撮影条件を先に用意します。判別不能な場面は、
ラベルを推測せず理由付きで評価対象から外します。選定・除外は推論前に記録します。
今後しきい値を調整する場合、そのための画像と最終評価の画像を撮影セッション単位で
分け、調整後の画像を同じ評価セットに混ぜないようにします。

結果と限界は `docs/accuracy.md` に日本語で記録しています。
